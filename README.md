# 🚴 AdventureWorks Sales & Performance Analysis

An end-to-end data analytics project analyzing customer trends, product revenue, and regional performance using **SQL, Excel, Power BI, and Tableau**.

---

## 🛠️ Tools Used
* **SQL:** Extracted, joined, and aggregated data from the AdventureWorks database.
* **Excel:** Built dynamic summary tables, KPI metrics, and exploratory models.
* **Power BI:** Created an interactive data model and sales performance dashboard.
* **Tableau:** Visualized geographic sales patterns and customer breakdown.

## 🔍 Key Business Insights
* **Revenue Drivers:** Road and Mountain bikes generated the bulk of total revenue.
* **Geographic Trends:** North America dominated total sales volume, while Europe showed steady quarter-over-quarter expansion.
* **Order Patterns:** Q3 showed the highest volume of purchases across multi-product orders.
